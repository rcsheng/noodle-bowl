### 12.4 The Spread — Multiple Choice

**File:** `app/games/spread.tsx`
**New lib:** `lib/spreadChoices.ts`

#### What changed

Replaced the 3-round bisection game with a single-tap multiple-choice format.

- Four choices are shown: the real answer plus three distractors.
- Distractors are generated by `lib/spreadChoices.ts` using random multipliers (pool: 0.2×–4.0×) applied to the truth, rounded to 2 significant figures, and shuffled using a seeded RNG keyed to the truth value (deterministic per question).
- All choices are within ~0.1×–10× of the truth (same order of magnitude).
- Choices render as a left-bar list matching the Lede style.
- Primary CTA: `LOCK IN` (disabled) → `LOCK IN B` (enabled, where B is the chosen letter).
- Reveal: choices locked in place (correct = green, wrong pick = accent), result card with verdict + real answer + points, explanation block.
- Scoring: correct = +10 pts, wrong = 0 pts.

#### `lib/spreadChoices.ts`

```ts
export function generateChoices(truth: number, rng?: () => number): number[]
export function buildChoicesForItem(item: SpreadItem): number[]
```

`buildChoicesForItem` uses a linear-congruential RNG seeded by `item.answer` for determinism.

#### Acceptance criteria

- [x] Four distinct choices, always including truth.
- [x] All choices positive, nicely rounded (2 sig figs), within 0.1×–10× of truth.
- [x] Single tap to select, `LOCK IN X` CTA.
- [x] Reveal shows correct/wrong state on each choice.
- [x] Scoring: +10 correct, 0 wrong.
- [x] Challenge/help modes pass selected value as answer string.
- [x] Compact masthead.
- [x] "Ask a Friend" text link.
- [x] `lib/__tests__/spreadChoices.test.ts` covers: length, truth inclusion, distinctness, positivity, magnitude bounds, large/small values.

### 12.5 Science or Fiction — Pick The Lie

**File:** `app/games/sof.tsx`

#### What changed

- **Confidence wager removed.** Scoring: correct = +10, wrong = 0. No negative scoring.
- **Mode toggle**: `STANDARD` / `WEIRD & TRUE` is a 2-button segmented control with a "Select mode" label above it. Active = ink fill + onDark text. Inactive = paper fill + ink border. testIDs: `sof-mode-standard`, `sof-mode-weird`. Hidden in challenge and help modes.
- **Header**: "Science or Fiction" title removed. Category name (`item.topic`) is the `frauncesBoldItalic` 22pt headline. Toggle label "Select mode" appears above the segmented control.
- **Intro text removed**: the `item.intro` field ("Three claims about X. Two are real; one is fabricated.") is no longer displayed.
- **"Tap the Fake" instruction**: `frauncesBoldItalic` 19pt (subordinate to category headline). Supporting line "Two are real · one is a lie" in muted italic 13pt below it.
- **Claim shuffle**: claims displayed in shuffled order via `shuffleIndices`. Fiction always authored at index 2 in data but may appear at any display position. Correctness uses original indices.
- **Mode pre-loading**: both Standard and Weird & True questions are pre-loaded on mount. Toggling switches which pre-loaded question is displayed — no new question is fetched on toggle. `handlePlayAgain` replaces only the current mode's slot.

## 15. Post-Alpha UX Refinements (TJ Feedback — May 2026)

### 15.1 Reveal layout reorder

**Affected files:** `app/games/lede.tsx`, `app/games/spread.tsx`, `app/games/sof.tsx`, `app/games/wave.tsx`, `app/games/quip.tsx`

**Problem:** On reveal, the result card renders below all claim/choice content. On SoF this means three expanded claim cards with explanations before the verdict — easily 3–4 screens of content. Users must scroll to see their outcome.

**Fix:** In the reveal phase, render the result card *before* the claim/choice list. The verdict is the most urgent information; explanations are supporting detail.

**Implementation:**

Lede reveal order:
1. choiceList (colored rows with ✓/✗ indicators)
2. resultCard (compact verdict · divider · points)
3. infoBox (explanation only — removed "THE REAL HEADLINE" label and full correct headline)

Spread reveal order:
1. choiceList (locked, color-coded with ✓/✗ indicators)
2. resultCard (compact verdict · divider · points)
3. infoBox (explanation)

SoF reveal order:
1. claimList (with explanations, ✓/✗ indicators on claim header)
2. resultCard (compact verdict · divider · points)
3. `scrollTo` auto-scrolls to resultCard on lock-in (100ms delay, scrollRef)

Wave, Quip:
- Result cards already compact; no layout reorder needed

### 15.3 Spread distractor decimal precision

**Affected file:** `lib/spreadChoices.ts`

**Problem:** When the truth value has decimal places (e.g. 4.7), distractors are generated via `roundToSigFigs(Math.round(truth * m))`. The inner `Math.round` strips the decimal before rounding, so all distractors are integers — visually inconsistent with a decimal truth.

**Fix:** Detect the number of decimal places in the truth value. When it is > 0, round distractors to that many decimal places using a dedicated `roundToDecimalPlaces` helper instead of `roundToSigFigs(Math.round(...))`. Integer truths retain existing behavior.

#### AC 15.3

- [ ] For a truth with N decimal places, all 4 choices have at most N decimal places.
- [ ] Integer truth values continue to produce integer choices (no regression).
- [ ] `roundToDecimalPlaces` is tested in `lib/__tests__/spreadChoices.test.ts`.
