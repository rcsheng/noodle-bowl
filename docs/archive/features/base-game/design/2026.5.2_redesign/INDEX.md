# Noodle Bowl — Redesign Handoff Package

This folder contains everything Claude Code needs to ship the Q2 redesign of the home tab plus three games (Lede, Spread, SoF).

## Contents

| File | Purpose |
|---|---|
| `README.md` | Order of work, suggested instruction to give Claude Code |
| `01-home-tab.md` | Home tab → Compact Index list |
| `02-lede.md` | Lede → Headline-First (no reporters) |
| `03-spread.md` | Spread → 3-round Bisection (with algorithm spec) |
| `04-sof.md` | SoF → Pick The Lie (one tap + wager) |
| `Home Screen Evaluation.html` | Interactive mock — open in a browser |
| `Games Evaluation.html` | Interactive mock — open in a browser |
| `mock-assets/` | JSX modules used by the two HTML mocks |

## Where to place this in the repo

Drop this whole folder into the codebase at:

```
noodle-bowl/designs/redesign-2026-q2/
```

Then commit and run Claude Code from the repo root.
