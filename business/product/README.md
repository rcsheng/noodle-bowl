# Product Management

This folder stores product management documents generated with the Claude Cowork **product-management** skills.

> Note: Core PRDs and technical specs live in `/docs/`. This folder is for working documents — sprint plans, roadmap updates, research synthesis, and stakeholder updates.

## Skills that output here

| Skill | What it produces |
|---|---|
| `product-management:write-spec` | Feature specs and PRDs |
| `product-management:roadmap-update` | Roadmap Now/Next/Later views |
| `product-management:sprint-planning` | Sprint plans with capacity and goals |
| `product-management:stakeholder-update` | Stakeholder update emails/docs |
| `product-management:metrics-review` | Metrics scorecards with trend analysis |
| `product-management:synthesize-research` | User research synthesis reports |
| `product-management:competitive-brief` | Competitive analysis briefs |
| `product-management:product-brainstorming` | Brainstorm outputs and problem-space exploration |

## Suggested subfolders

- `roadmap/` — roadmap snapshots by quarter
- `sprints/` — sprint plans by sprint number
- `research/` — user research synthesis
- `metrics/` — weekly/monthly metrics reviews
- `competitive/` — competitive analysis briefs

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
