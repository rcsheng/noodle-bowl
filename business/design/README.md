# Design

This folder stores design assets and research generated with the Claude Cowork **design** skills.

## Skills that output here

| Skill | What it produces |
|---|---|
| `design:user-research` | Research plans, interview guides, usability tests |
| `design:research-synthesis` | Synthesized findings, themes, recommendations |
| `design:design-critique` | Structured design feedback reports |
| `design:design-handoff` | Developer handoff specs (layout, tokens, interactions) |
| `design:accessibility-review` | WCAG 2.1 AA audit reports |
| `design:design-system` | Design system audits and component docs |
| `design:ux-copy` | Microcopy, CTAs, error messages, onboarding text |

## Suggested subfolders

- `research/` — interview notes, usability findings, synthesis reports
- `handoff/` — developer specs per feature
- `audits/` — accessibility and design system audits
- `copy/` — UX copy drafts

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
