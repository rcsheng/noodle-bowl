# Sales

This folder stores sales documents generated with the Claude Cowork **sales** skills.

## Skills that output here

| Skill | What it produces |
|---|---|
| `sales:account-research` | Company/person research and sales intel |
| `sales:draft-outreach` | Personalized cold outreach emails |
| `sales:call-prep` | Pre-call account context, attendee research, agenda |
| `sales:call-summary` | Call notes, action items, follow-up emails |
| `sales:pipeline-review` | Pipeline health analysis and weekly action plan |
| `sales:forecast` | Weighted forecast with best/likely/worst scenarios |
| `sales:competitive-intelligence` | Interactive competitor battlecards |
| `sales:create-an-asset` | Landing pages, one-pagers, pitch decks |
| `sales:daily-briefing` | Daily prioritized sales briefings |

## Suggested subfolders

- `outreach/` — prospect research and cold email drafts
- `calls/` — call prep and post-call summaries
- `pipeline/` — pipeline reviews and forecast reports
- `assets/` — sales one-pagers, landing pages, decks
- `competitive/` — battlecards

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
