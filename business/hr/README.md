# Human Resources

This folder stores HR documents generated with the Claude Cowork **human-resources** skills.

## Skills that output here

| Skill | What it produces |
|---|---|
| `human-resources:recruiting-pipeline` | Pipeline stage trackers |
| `human-resources:interview-prep` | Interview plans, competency questions, scorecards |
| `human-resources:draft-offer` | Offer letters and total comp packages |
| `human-resources:onboarding` | Onboarding checklists and first-week plans |
| `human-resources:performance-review` | Review templates, self-assessments, calibration prep |
| `human-resources:comp-analysis` | Compensation benchmarking and band analysis |
| `human-resources:org-planning` | Headcount plans and org design docs |
| `human-resources:people-report` | Headcount, attrition, and diversity reports |
| `human-resources:policy-lookup` | Plain-language policy summaries |

## Suggested subfolders

- `recruiting/` — pipeline trackers, interview kits, offer letters
- `onboarding/` — onboarding plans per new hire
- `performance/` — review cycles
- `org/` — headcount plans, org charts

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
