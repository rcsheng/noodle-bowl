# Finance

This folder stores financial documents generated with the Claude Cowork **finance** skills.

## Skills that output here

| Skill | What it produces |
|---|---|
| `finance:financial-statements` | P&L, balance sheet, cash flow statements |
| `finance:variance-analysis` | Budget vs. actual analysis and commentary |
| `finance:journal-entry` / `finance:journal-entry-prep` | Journal entry workpapers |
| `finance:reconciliation` | Account reconciliation reports |
| `finance:close-management` | Month-end close checklists and calendars |
| `finance:sox-testing` | SOX sample selections and testing workpapers |
| `finance:audit-support` | Audit documentation and control testing |

## Suggested subfolders

- `statements/` — monthly/quarterly financial statements
- `close/` — month-end close packages by period
- `variance/` — budget vs. actual reports
- `reconciliations/` — account rec workpapers

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
