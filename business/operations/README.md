# Operations

This folder stores operational documents generated with the Claude Cowork **operations** skills.

## Skills that output here

| Skill | What it produces |
|---|---|
| `operations:process-doc` | Process flowcharts, RACIs, and SOPs |
| `operations:process-optimization` | Process improvement analyses |
| `operations:runbook` | Step-by-step operational runbooks |
| `operations:status-report` | Weekly/monthly status reports with KPIs and risks |
| `operations:risk-assessment` | Risk registers and mitigation plans |
| `operations:change-request` | Change management requests with rollback plans |
| `operations:capacity-plan` | Resource utilization and capacity forecasts |
| `operations:vendor-review` | Vendor evaluations and TCO analyses |
| `operations:compliance-tracking` | Compliance requirement trackers and audit readiness |

## Suggested subfolders

- `processes/` — SOPs and process docs
- `runbooks/` — operational runbooks
- `reports/` — weekly/monthly status reports
- `risk/` — risk registers
- `vendors/` — vendor reviews and evaluations

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
