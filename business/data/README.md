# Data & Analytics

This folder stores data analysis outputs generated with the Claude Cowork **data** skills.

## Skills that output here

| Skill | What it produces |
|---|---|
| `data:analyze` | Analysis reports from quick lookups to full deep-dives |
| `data:explore-data` | Dataset profiling — shape, quality, distributions |
| `data:statistical-analysis` | Descriptive stats, hypothesis tests, trend analysis |
| `data:build-dashboard` | Interactive HTML dashboards with charts and filters |
| `data:create-viz` / `data:data-visualization` | Publication-quality charts and plots |
| `data:write-query` / `data:sql-queries` | SQL queries for the data warehouse |
| `data:validate-data` | QA reports on methodology and accuracy |

## Suggested subfolders

- `reports/` — ad-hoc and recurring analysis reports
- `dashboards/` — self-contained HTML dashboard files
- `queries/` — reusable SQL queries
- `charts/` — exported chart images and interactive plots

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
