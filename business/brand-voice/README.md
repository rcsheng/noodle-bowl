# Brand Voice

This folder stores brand voice assets generated with the Claude Cowork **brand-voice** skills.

## Skills that output here

| Skill | What it produces |
|---|---|
| `brand-voice:generate-guidelines` | Brand voice guidelines document |
| `brand-voice:brand-voice-enforcement` | On-brand content drafts and rewrites |
| `brand-voice:discover-brand` | Discovery reports from existing materials |

## Suggested file types

- `guidelines/` — core brand voice guide, tone & messaging pillars
- `templates/` — approved copy templates (emails, social posts, ads)
- `reviews/` — brand compliance review outputs

> Files in this folder are git-ignored. Keep originals backed up outside this repo.
